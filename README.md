# medium-images

Permanent image hosting for the daily Medium / dev.to articles.

- Images live in dated folders (`YYYY-MM-DD/`).
- Permanent URL form: `https://raw.githubusercontent.com/beechrasta/medium-images/main/YYYY-MM-DD/name.jpg`
- Files are uploaded automatically by the daily article workflow. Please don't delete or rename them; old articles link to these URLs.
